# Тасымалдану тексерімі

Негізгі және бос орын/қазақша/орысша таңбалары бар көшірмеде конвейер сәтті орындалды.
180 бастапқы жауап → 21 LT18 шығарылды → 159 ересек. 24/24 эталон, 134/134 шығыс тексерімі, 8/8 тест өтті.
CSV, ғылыми PNG, XLSX ұяшықтары және толық мақаланың Word XML мазмұны екі орында сәйкес.
Жаңартылған хаттама protocol_revision.json хешімен тексерілді. Қалған бастапқы файлдар мен ғылыми код резервпен бірдей.
Python және қажетті кітапханалар runtime ішінде; лицензиялар мен нұсқалар сол жерде. Node, artifact-tool, Office есептеу үшін қажет емес.
Іске қосу: жоба түбірінен .\RUN_REVIEW.cmd
Қате кіріс кезінде nonzero exit қайтарылады; бұрын жарияланған мақала сақталады.
Сынақ сол Windows x64 компьютерінде жүргізілді; бөлек таза VM/компьютерде тексерілген жоқ.
Желі Python audit hook арқылы бұғатталды; бұл операциялық жүйе деңгейіндегі желіні ажырату емес. Native DLL әрекеттері OS sandbox-пен бақыланбады.
Автор жаңартқан хаттама PDF-і пакетке енгізілді. Бұл іске қосу құжаттың этикалық мазмұнын растау болып саналмайды.
Таза пакет: BDSF_reviewer_package.zip. work ішіндегі резервтер мен аралық сынақтар архивке кірмейді.
PACKAGE_MANIFEST.csv — жеткізілген нұсқаның SHA-256 манифесі; қайта есептеуден кейін уақыт белгілері бар файлдардың хэші өзгеруі мүмкін.
