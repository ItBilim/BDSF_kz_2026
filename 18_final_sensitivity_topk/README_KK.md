# RQ2 және RQ3 нәтижелерін толықтыру

Жоба түбірінен іске қосу:

```powershell
.\18_final_sensitivity_topk\RUN_FINAL.cmd
```

Қайталанымдылықты тексеру:

```powershell
.\18_final_sensitivity_topk\RUN_FINAL.cmd --verify-repeat
```

Қажет болса, осы бөлімнің polychoric permutation есептерін кэшсіз қайта есептеу:

```powershell
.\18_final_sensitivity_topk\RUN_FINAL.cmd --recompute-poly
```

Жоба ішіндегі runtime/python пайдаланылады. 00–17 бөлімдер өзгертілмейді. Бұл каталог жобаның ішіндегі жалғастыру модулі; оны жеке көшіріп іске қосу үшін жеткіліксіз. 16 бөлімнің polychoric коды, 17 бөлімнің тексерілген нәтижелері және негізгі деректер керек. Жаңа пакет не желілік байланыс талап етілмейді.

## Не қайта пайдаланылды

- S0–S4 бойынша M, SD, α, ω, KMO, Bartlett және Pearson PA — 17 бөлімнің нәтижелері. Деректердің хештері, қатысушылар құрамы, M/SD/α/KMO/Bartlett және PA-ның бақыланған eigenvalue-лары тексеріледі.
- S0 polychoric PA — 16 бөлімнің тексерілген нәтижесі.
- M1/M2/M3 баллдары мен Top-K жиындары — 17 бөлімнен. M3 формуласындағы бұрынғы regression коэффициенттері, item mean және population SD сақталады; балл бағыты оң екені тексеріледі.

## Не жаңадан есептелді

- S1, S2, S4 үшін polychoric PA: әр сұрақ бағанын жеке араластыратын 200 permutation, seed=20261107, 95-процентиль шегі. Әр permutation-да polychoric корреляциялар қайта бағаланады.
- S3 жазбалары S1-мен бірдей болғандықтан, оның polychoric нәтижесі S1-ден алынады.
- Overlap@K=intersection/K және N_changed=K−intersection.
- Таңдалған техникалық ID жиындары; олар бұрынғы P-кодтардан тексерілген бастапқы ID сәйкестігі арқылы алынған.

Polychoric бағалау және қажет болған матрица түзетуі 16 бөлімнің әдісімен бірдей. `diagnostics` ішінде eigenvalue, null95, матрицалар, жұптық сирек ұяшықтар және түзету туралы мәліметтер бар. 200 permutation нәтижесі Monte Carlo жуықтау екенін ескеріңіз. Фактор саны осы PA ережесі бойынша бағаланады; бұл CFA немесе толық measurement invariance дәлелі емес.

`RQ2_SENSITIVITY.csv`: M және SD — негізгі M1 баллы; Cronbach_alpha — raw α; McDonald_omega — 14 сұрақтың бақыланатын тең қосындысына қатысты бұрынғы бір факторлы congeneric ω. Ол M1 композитінің сенімділігімен автоматты тең емес. Bartlett_df=91, p түзетілмеген. delta_M, delta_alpha, delta_omega = сценарий − S0. PA_factors — кездейсоқ 95% шектен жоғары eigenvalue саны.

`RQ3_TOPK_RESULTS.csv`: Jaccard=intersection/union; Overlap_at_K=intersection/K (0–1 үлесі); N_changed=K−intersection (бір жақтағы ауысу). Симметриялық айырма 2×N_changed. Spearman/Kendall — толық 159 адам рейтингі, сондықтан үш бюджетте қайталанады. Тең баллды таңдауда бастапқы кодтағыдай 10 ондыққа дөңгелектелген балл және техникалық ID-дің лексикографиялық реті қолданылады; ранг корреляциясында тең баллдарға орташа ранг берілген.

## Тексеру тәртібі

Бағдарлама бұрынғы валидациялардың PASS күйін және нәтижелер хештерін тексереді. 21 кәмелетке толмаған адамның ешбір аналитикалық жиынға кірмегені ID жиындарының дәл сәйкестігімен тексеріледі. Әр Top-K тізімінде дәл K бірегей ID болуы тиіс. Сүзгілер S4-те union арқылы біріктіріледі; бір адам екі рет шығарылмайды.

Кэш бастапқы сандық деректер, polychoric әдіс коды, seed және permutation саны арқылы тексеріледі. Әр жаңа polychoric сценарийде екі permutation тәуелсіз қайта есептеліп, кэшпен салыстырылады. `--verify-repeat` өткен іске қосудың барлық сандық CSV хештерін жаңа іске қосумен салыстырады. Бұл тексеруде кэш пайдаланылғаны жасырылмайды; толық cold run үшін `--recompute-poly` бар.

Кез келген міндетті тексеру бұзылса, бағдарлама nonzero exit code қайтарады және STATUS.json ішінде FAIL жазады. FAIL немесе RUNNING тұрған каталогты аяқталған нәтиже ретінде пайдаланбаңыз. Жетіспейтін мән нөлмен толтырылмайды.
