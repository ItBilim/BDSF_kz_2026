# BDSF Kazakhstan бағалау спецификациясы

## Мақсаты

14 мінез-құлық сұрағын бірыңғай 0–100 шкаласына ауыстыру және төрт теориялық өлшем арқылы жалпы BDSF көрсеткішін есептеу.

## Балл беру

- Ешқашан / Никогда: 0
- Сирек / Редко: 25
- Кейде / Иногда: 50
- Жиі / Часто: 75
- Әрқашан / Всегда: 100

Q10 сұрағы зиянды бағдарламалардан қорғауды қамтамасыз ету туралы арнайы тұжырымдарды қолданады. Оның жауаптары мағыналық деңгейіне сәйкес сол 0–100 шкаласына көшіріледі. Бос жауап нөлге айналдырылмайды.

## Өлшемдер

- D1 = Q01–Q04 орташа мәні.
- D2 = Q05–Q07 орташа мәні.
- D3 = Q08–Q11 орташа мәні.
- D4 = Q12–Q14 орташа мәні.

## Жалпы көрсеткіш

BDSF = (D1 + D2 + D3 + D4) / 4.

Төрт өлшемнің әрқайсысы жалпы нәтижеге 25% үлес қосады. Барлық 14 сұрақты тікелей орташалауға болмайды, себебі өлшемдердегі индикатор саны бірдей емес.

## Деңгейлер

Жіктеу алдында BDSF көрсеткіші екі ондық таңбаға дейін дөңгелектенеді.

- 0.00–33.32: төмен.
- 33.33–66.66: орташа.
- 66.67–100.00: жоғары.

Дөңгелектеу ережесі санаттар арасындағы математикалық бос аралықты жояды. Бұл шектер эмпирикалық норматив немесе клиникалық cut-off емес; олар қосымша сипаттамалық интерпретация ретінде сақталады.
